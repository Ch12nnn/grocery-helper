# 🥬 上海买菜助手：手机/电脑双端实时比价系统 (Shanghai Grocery Companion)

> 专为上海市民量身打造的买菜比价助手。
> **真正解决在菜市场、超市（手机 4G/5G 移动网络）下的即时比价需求**：随时随地秒级开机查价、自动计算与上海市发改委官方菜场零售均价的差额与涨跌百分比、支持商超价格天花板比对、支持五花肉/排骨/牛腩/番茄等民间别名联想识别，支持菜市场地下室弱网离线秒开！

---

## 📱 核心亮点：买菜现场（手机 4G/5G）如何使用？

你在菜市场或超市买菜时，手机使用的是移动蜂窝网络（4G/5G），**无需家里电脑开机，也无需局域网**。本项目提供专为移动买菜场景设计的解决方案：

### 🌟 1. 免费在线托管（⭐ 手机 4G/5G 随时秒开，电脑完全不用开机）
本项目完全支持**静态化部署**（前端纯 JavaScript 运算 + 静态数据）：
- **GitHub Pages 部署（已开通）**：
  1. 在仓库页面点击 **Settings** -> **Pages**，在 **Build and deployment** 下将 **Branch** 选择为 `main`，目录选择 `/docs`；
  2. GitHub 生成的公网 HTTPS 专属网址：
     `https://ch12nnn.github.io/grocery-helper/`

#### 📲 手机买菜实用小窍门：
* 在手机自带浏览器（如 Safari、Edge、Chrome）中打开网址；
* 点击浏览器下方的 **“分享”**（或菜单） -> 选择 **“添加到主屏幕”**；
* 手机桌面上就会出现一个类似独立 App 的 **“上海买菜助手”** 图标，出门买菜时一点就开！

---

### 📶 2. 地下室弱网与离线可用
- 首次加载后，蔬菜价格数据自动保存在手机本地浏览器存储中；
- 即使进入菜市场地下负一层、4G 信号微弱或完全无网，依然能够正常查询、计算与比价！

## 🔍 现场比价计算器功能演示

在手机或电脑打开网页后：
1. **快捷选菜**：
   * 首屏优先展示你的 **“⭐ 我的常买”** 菜品（如青菜、西红柿、排骨、鸡蛋等）；
   * 支持分类胶囊（🥬蔬菜、🥩肉蛋、🐟水产、🍎水果）或实时模糊搜索。
2. **输入单价**：
   * 看到摊主报价后，在输入框填入单价（如 `5.0` 元/斤），支持 `+0.5`、`-0.5` 快捷微调或一键填入均价。
3. **秒级计算差额与百分比**：
   * **菜场零售均价（还价基准）**：例如青菜 `4.16 元/斤`（上海市发改委采样 39 家典型农贸菜场均价）
   * **大型商超均价（价格上限）**：例如青菜 `2.86 元/斤`（大润发、世纪联华、农工商等 17 家商超）
   * **差额与百分比**：秒级显示高出或低出百分比；
   * **智能购买建议**：
     * 🟢 **🔥 超值实惠**（低 15% 以上）：成色新鲜建议果断入手；
     * 🔵 **✅ 价格公道**（-15% ~ +10%）：处于菜场合理波动区间；
     * 🟡 **⚠️ 略微偏贵**（+10% ~ +30%）：可挑拣好品相或与摊主还价；
     * 🔴 **🛑 明显偏贵**（+30% 以上）：高出均价过多，建议换一家摊位或去超市平价专柜。
   * **区间参考**：同时展示该菜品在全上海各大菜场的最低价与最高价。

## ⭐ 手机端自定义我的常买菜品

* 点击顶部 **“⭐ 我的常买”** 选项卡；
* 列出发改委官方监测的全部 64 种食材，打勾/取消打勾即可任意定制；
* 设置自动保存在手机本地（`localStorage`），每次打开手机直接优先显示你常吃的菜！

## 💻 本地电脑快速启动

如果想在电脑大屏上查看行情或本地测试：
* 双击运行 **[`start_web.bat`](file:///D:/Projects/grocery-helper/start_web.bat)**，电脑浏览器将自动打开本地页面；
* 运行单次菜价数据同步与行情查看：运行 **[`run.bat`](file:///D:/Projects/grocery-helper/run.bat)**。

## 📁 项目结构

```
.
├── docs/                       # 静态网页根目录（部署至 GitHub Pages 供手机秒开）
│   ├── index.html              # 手机/电脑自适应比价器应用（带密码锁与离线缓存）
│   └── data.json               # 发改委全量 64 种生鲜食材价格数据库
├── build_static.py             # 静态数据构建脚本（抓取发改委最新数据更新 docs/data.json）
├── web_app.py                  # 本地测试用的轻量多线程 Web 服务端
├── config.example.json         # 配置文件模板（公开）
├── sh_market_price.py          # 核心爬虫与解析引擎（分离菜场均价与大型商超均价）
├── main.py                     # 控制台命令行数据同步与行情查看入口
├── start_web.bat               # Windows 双击一键启动本地测试服务
├── run.bat                     # Windows 双击一键同步最新菜价数据
└── README.md                   # 本文档
```
